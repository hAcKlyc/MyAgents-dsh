# MyAgents-dsh 0.1.25

Hosts can supply additional workspace roots in a session's execution environment using protocol 6.3. On macOS and Linux, the existing workspace permission mode applies to the primary directory and its configured additional roots. Relative paths still resolve from the primary workspace. The Windows restricted Shell continues to use the primary workspace only.

The release builds use Node.js 24.20.0.

Host 可以通过协议 6.3 为会话传入关联目录。macOS 和 Linux 沿用现有工作区权限模式，同时覆盖主目录和关联目录。相对路径仍从主目录解析。Windows 受限 Shell 仍只使用主目录。
