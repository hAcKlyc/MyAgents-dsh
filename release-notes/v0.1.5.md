# MyAgents-dsh 0.1.5

This release carries the Windows release-build fix from v0.1.4 and refreshes the accepted patched-DSH artifact identity for this exact version. The artifact inventory is checked against the pinned DSH source before four-platform native validation and publication.

Runtime composition can fetch a missing transitive npm dependency while preferring cached packages. GitHub-hosted builds leave large temporary dependency trees for runner teardown after the verified artifact is promoted. The MyAgents and standalone Host protocol remain compatible.
