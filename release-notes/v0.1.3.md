# MyAgents-dsh 0.1.3

This version completes the Windows local setup and integration build path. Setup accepts Git's exact text pointers when Windows cannot create symlinks, primes the patched DSH dependency store with the selected Node runtime, and cleans temporary Git worktrees reliably on Windows.

Runtime composition and its tests now use the platform shell and Windows process-signal behavior where appropriate. The Windows x64 local handoff and MyAgents Dev installer were built and verified from this work; live-provider acceptance remains a separate check before publication. The same Host protocol remains available to other integrators.
