# MyAgents-dsh 0.1.19

- Upgrade the integrated engine to DeepSeek Harness 0.2.1-rc.2, with native asynchronous child execution, waiting and descendant settlement. Child agents retain the Host workspace, approval policy and model routing.
- Preserve existing native V4 session histories and released child descriptors, including literal persona text and settlement ownership. Existing instruction reconciliation, compaction, file editing and Provider-content fixes remain in place.
- Support explicitly declared per-model conversation updates through the existing Provider configuration, so supported prompt and tool changes use the same facts in model metadata and actual requests.
- Preserve literal Host/Skill context and streamed tool arguments while updating pi-ai to 1.1.0. Align shared schema and image dependencies to avoid incompatible duplicate installations.

The protocol remains 6.2.0. The Runtime targets macOS arm64, macOS Intel x64, Windows x64 and Linux x64; each Release archive is built and validated on its native runner. The publication workflow appends exact upstream and patched-artifact provenance.

Old histories remain readable without migration. New native child writes are not guaranteed to be readable by older Runtime versions; this release does not promise downgrade compatibility. Additional search, directory/worktree switching, plugin-market, browser computer-use and daemon capabilities are outside this upgrade.
