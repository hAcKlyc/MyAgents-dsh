# MyAgents-dsh 0.1.14

- Use the official DSH 0.2.0-rc.2 JSONL persistence for native conversations, including its checksummed compressed log, buffering, leases and recovery. Remove the custom SQLite event backend.
- Preserve product rewind, fork, deletion and workspace file recovery through a small coordination store. Forks use the official inherited-event seed; interrupted unpublished mutation candidates can be resumed safely.
- Use the official inherited-event scope for branch operations, permissions and plans. Keep every retained turn available for rewind/fork, including cold recovery and nested forks, with one canonical boundary per turn.
- Keep earlier file and directory recovery available across successive rewind generations and subsequent forks, using the existing committed mutation lineage and exact retained cuts.
- Preserve native event payloads, including images, without imposing product metadata limits on conversation events.
- Remove development-era persistence schemas. This prelaunch release does not migrate old development sessions; obsolete data is cleared manually outside the Runtime.

The Runtime targets macOS arm64, macOS Intel x64, Windows x64, and Linux x64. Each Release archive is built and validated on its native runner; the publication workflow appends exact upstream and patched-artifact provenance.
