# MyAgents-dsh 0.1.20

- Restore completed Task sessions after their Runtime process has stopped, even when the next Host permission mode differs from the completed operation's mode.
- Validate the existing permission history before applying the next configuration. Keep exact grants when the policy is unchanged, and reject policy changes while unfinished work still depends on its original permissions.
- Persist cold-start configuration through the existing Agent factory before making the Session available. Recover accounted interrupted configuration writes while continuing to refuse corrupt or unexplained history.
- Align MCP test transports with the component's own SDK contract so verified builds do not depend on an unrelated root SDK type.

The protocol remains 6.2.0 and the upstream DeepSeek Harness version remains 0.2.1-rc.2. Existing histories are preserved without rewriting past execution identities or changing Host Session defaults. This release adds no new storage, scheduler, transport or permission bypass.

Each macOS arm64, macOS Intel x64, Windows x64 and Linux x64 archive is built and validated by the native Release workflow. Exact upstream and patched-artifact provenance is appended by the publisher.
