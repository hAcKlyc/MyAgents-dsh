# MyAgents-dsh 0.1.22

Web tools now use the local machine's network without extra destination restrictions.

- Fetch local development servers, private IPv4/IPv6 services and custom ports through the existing Web tools.
- Use Fake-IP/TUN networking without public-address rejection or a special permission-mode switch.
- Remove the hostname, port and address-class allow/deny rules from native fetching and standalone search transport. Existing tool approvals, HTTP/TLS validation, proxy routing and request resource limits remain in effect.
- Keep managed MCP connections confined to their configured origin and credential scope while sharing the same destination-capable HTTP transport.
