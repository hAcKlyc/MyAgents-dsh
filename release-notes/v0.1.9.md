# MyAgents-dsh 0.1.9

This release introduces three integrated permission modes: 请求批准, 工作区自主, and 完全自主. The first two use the upstream DSH workspace-write sandbox for file and shell mutations; 完全自主 uses danger-full-access. File reads are no longer restricted to a MyAgents-dsh directory allowlist. 请求批准 asks before commands, web activity, and external tools, while allowing ordinary file tools without an extra approval. A denied sandbox operation can request one approval to retry with broader access.

The Host protocol now carries the three modes directly. Session-scoped “always allow” rules remain available for ordinary tool approvals. The accepted patched DSH artifact has been rebuilt with its sandbox file-system package.
