# MyAgents-dsh 0.1.18

- Delete sessions whose stored history cannot be read without first restoring an Agent or contacting a model. Deletion keeps the existing storage transaction, writer leases and recovery receipts, including retries after interrupted physical cleanup.
- Keep verified schema dependencies consistent during source setup and Runtime composition, avoiding failures caused by incompatible duplicate dependency versions.

The protocol advances to 6.2 with an explicit storage-only deletion target. The upstream engine remains DSH 0.2.0-rc.2. The Runtime targets macOS arm64, macOS Intel x64, Windows x64 and Linux x64; each Release archive is built and validated on its native runner. The publication workflow appends exact upstream and patched-artifact provenance.

This release provides a deletion recovery path; it does not claim to repair every native session resume failure or rewrite unreadable history.
