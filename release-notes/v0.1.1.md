# MyAgents-dsh 0.1.1

First verified MyAgents-hosted DSH Runtime release for macOS ARM and Intel, Linux x64, and Windows x64.

MyAgents-dsh provides the Host protocol, integrated Agent tools, native Runtime dependencies, and a versioned manifest for client packaging. MyAgents uses this release directly, and other Hosts can integrate through the same protocol and artifact contract.

This release aligns the official DeepSeek Messages route across Runtime acceptance and the bundled test and Web Host profiles. It also corrects Windows path and permission assertions in the release tests and adds Windows checks to regular CI.
