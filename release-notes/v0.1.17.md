# MyAgents-dsh 0.1.17

- Connect to Host-configured local HTTP MCP servers, including the MyAgents managed browser, without rejecting loopback addresses. External MCP connections retain the existing transport, credential, permission and lifecycle owners.
- Verify packaged source inventories against the files actually shipped and preserve final Runtime artifact authority through native handoff generation.

The upstream engine remains DSH 0.2.0-rc.2 and the protocol remains 6.1. The Runtime targets macOS arm64, macOS Intel x64, Windows x64 and Linux x64. Each Release archive is built and validated on its native runner; the publication workflow appends exact upstream and patched-artifact provenance.
