# MyAgents-dsh 0.1.24

Native subagents can address another member of the same tree by name or Session ID. Harness owns message delivery and enforces tree membership. The Host can resume a nested agent while its creator stays offline. Shared task assignments keep their Host attribution when they wake the assigned agent.

The runtime now uses Harness's typed session projections and its separate native and PTC tool executors. This retires the local projection-registration patch.

## Session compatibility

This update uses DeepSeek Harness 0.2.2-rc.5's official subagent catalog format. Creating a subagent writes a version 3 catalog entry in its **parent** Session, including when that parent was originally created by an earlier release. MyAgents-dsh 0.1.23 cannot reopen that parent after this write. Reopening it requires the upgraded runtime or a backup of the Session store taken before the write.

升级后创建子 Agent 时，其父会话会写入官方第 3 版目录记录。即使父会话最初由旧版创建，退回 MyAgents-dsh 0.1.23 后也无法打开这个父会话。需要回退的用户请在创建子 Agent 前备份会话存储。

When a completed v0.1.23 subagent receives its first follow-up directly from the child panel after upgrading, it can reply to text, but a tool call can fail with `tool_catalog_stale`. Ask the parent to send that same child a new task once. In testing, the child could then read files from panel follow-ups, including after restarting MyAgents. Its identity and history were preserved.

升级后，如果从子 Agent 面板直接给 v0.1.23 已完成的旧任务追加指令，调用工具时可能遇到 `tool_catalog_stale`。从父对话给原子 Agent 发一次新任务即可。实测随后从面板读文件成功，重启后仍有效，原会话和历史均保留。
