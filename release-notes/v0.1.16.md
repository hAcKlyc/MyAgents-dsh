# MyAgents-dsh 0.1.16

- Transfer complete declarative extension snapshots through immutable JSON attachments when their combined resources exceed the control-frame limit. Keep all Skills and commands available without increasing the frame limit.
- Validate attachment size, SHA-256, UTF-8 and the canonical snapshot before applying the existing atomic component replacement. Continue to accept inline snapshots.
- Acquire and release extension attachment leases under component authority before a Session binds, including cleanup of stale responses.

Protocol 6.1 adds the optional attachment reference to `extension/replace`. Hosts using this path must select a matching Runtime; existing inline requests remain compatible.

The upstream engine remains DSH 0.2.0-rc.2. The Runtime targets macOS arm64, macOS Intel x64, Windows x64 and Linux x64. Each Release archive is built and validated on its native runner; the publication workflow appends exact upstream and patched-artifact provenance.
