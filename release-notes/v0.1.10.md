# MyAgents-dsh 0.1.10

This release fixes permission-mode changes in an existing MyAgents Session. Changes made while a turn is running take effect on the next query without interrupting the active turn. Returning to an earlier mode now keeps approval revisions distinct, so Bash approval and one-operation sandbox elevation continue to work. Native DSH approval notices no longer make a later configuration update require Session recovery.

The three modes introduced in 0.1.9 remain: 请求批准, 工作区自主, and 完全自主.
