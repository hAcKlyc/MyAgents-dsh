# MyAgents-dsh 0.1.12

- Use one native DSH tool composition. Remove the obsolete `ma_first` strategy, custom file/search implementations, and the duplicate subagent lifecycle; keep Host permission, workspace, credential, proxy, and checkpoint integration in the native pipeline.
- Fix native child writes to new directories, child attachment visibility, and the distinction between native Agent IDs and Host Agent identities used by collaboration tools.
- Route large process outputs through native DSH spill storage, correct native continuation/settlement projections, and provide actionable task dependency errors while preserving shared-task visibility boundaries.
- Execute native search with the Host-selected ripgrep binary, allowing different package locations and platform path aliases without duplicate authority checks.
- Preserve native WebFetch presentation with the product network/content Provider. Fix proxy response handling and retain working HTML and PDF extraction.
- Reduce Runtime delivery size by removing source maps, type declarations, package-root test/example/CI resources, debug symbols, and native prebuilds for other targets. Preserve target-specific native addons/helpers, PDF assets, package manifests, and licenses.
- Remove conformance-only packages from production Runtime dependencies and unused source copies from the compiled OpenAI and Anthropic SDK distributions. Keep production module formats and Provider capabilities.
- Make native Release verification independent of model credentials and Provider availability. Fix the conformance fixture to request foreground delegation with the native `run_in_background` parameter. Preserve complete diagnostics for optional live campaigns.
- Update tool, lifecycle, network, and packaging documentation to reflect the current native-only architecture. Verify composition behavior rather than generated prompt snapshots.

The Runtime targets macOS arm64, macOS Intel x64, Windows x64, and Linux x64. This Release's target archives are built and validated separately on their native runners. The publication workflow appends exact upstream DSH and patched-artifact provenance below.
