# MyAgents-dsh 0.1.11

- Upgrade the official DeepSeek Harness foundation to 0.2.0-rc.2 and the provider adapter dependency pi-ai to 0.87.1. Adopt upstream recovery for interrupted tool calls and its requested-model replay fixes.
- The default dsh_first strategy uses official fresh/forked subagents, continuation messages and turn interruption, with DSH owning lifecycle and history. Personal task lists are private by default; the root shared list exposes only assigned/offered work to children.
- Task lists support deletion with dependency cleanup, corrected/reopened status, and no-op updates without extra revision changes. Personal lists remain Agent-local; shared tasks retain explicit assignment and atomic claims.
- Use the official list_agents plugin now that upstream fixes its export; remove the local adapter.
- Native subagent limits follow Host settings, with default depth two. Task notifications reread current assignments, and fork-inherited parent checkpoint/task facts do not become child-owned facts.
- Correlate native child relays and settlement notices with root operations so idle reports, interrupted turns and subsequent queued inputs do not strand the conversation.
- Parse inline Host Skill frontmatter and arguments consistently with filesystem skills.
- Retain Host permission, workspace, credential and proxy ownership. Reduce generated documentation noise in the official file-tool patch without changing its runtime behavior.

- Fix continuable children failing after a Host configuration change: subsequent turns use the dispatching message's operation and permission policy instead of the creation-time configuration.
