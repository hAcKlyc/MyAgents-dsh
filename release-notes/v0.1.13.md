# MyAgents-dsh 0.1.13

- Ignore provider-added argument decorations in declared tool inputs, including the `reason` added to empty Plan schemas. Keep business argument validation in the selected executor so an invalid call does not cancel the entire assistant tool batch.
- Remove native-Promise shape restrictions from trusted runtime callbacks. Async instrumentation and Promise subclasses no longer reject successful Plan, task, checkpoint, attachment, Hook, or component operations.
- Preserve complete declarative MCP and Host tool input schemas. Do not apply the unrelated structured-output schema subset to foreign tool declarations.
- Accept standard MCP metadata and structured/resource results. Preserve usable text when optional image publication or unsupported media cannot be rendered, while retaining bounded output, credential redaction, cancellation, and current-authority checks.
- Treat question heading brevity and short option labels as presentation guidance. Allow omitted `multiSelect` and repeated question text while keeping independent answer identities and bounded forms.
- Default omitted Provider input modalities to text and accept either ordering of text/image capabilities.

The Runtime targets macOS arm64, macOS Intel x64, Windows x64, and Linux x64. The pinned upstream DSH source and patch series are unchanged. Each Release archive is built and validated on its native runner; the publication workflow appends exact upstream and patched-artifact provenance.
