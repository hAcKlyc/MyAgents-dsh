# MyAgents-dsh 0.1.4

This release fixes the four-platform release build after the v0.1.3 tag exposed a missing npm cache entry on Windows. Runtime composition now uses cached packages when available and downloads missing dependencies during the release build. GitHub-hosted builds also leave large temporary dependency trees for the ephemeral runner to discard, avoiding a lengthy cleanup after verification.

The Runtime and Host protocol remain compatible with the MyAgents integration and the standalone Host interface.
