# MyAgents-dsh 0.1.7

This release fixes the Windows native Release build when a transitive Runtime dependency is absent from npm's initial cache. Runtime composition now prefers cached packages and downloads missing ones for both installation passes, while continuing to verify the final package tree and artifact. Its GitHub Actions output is reduced to verification digests so large JSON evidence does not overwhelm the job log.

The patched DSH artifact identity is regenerated for this exact version. The MyAgents integration and standalone Host protocol remain compatible.
