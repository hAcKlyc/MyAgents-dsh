# MyAgents-dsh 0.1.2

First verified MyAgents-hosted DSH Runtime release for macOS ARM and Intel, Linux x64, and Windows x64.

The Runtime now configures DSH automatic compaction for smaller context windows, including 16K-token models. Native acceptance checks verify clarification, formal plan approval, and the resulting file change through Host behavior without depending on which file-tool strategy is selected.

This release also makes Windows Runtime composition verify canonical source paths across Windows path spellings and runs that composition check in regular Windows CI. MyAgents can select this version through its single DSH release version setting; other Hosts can use the same versioned manifest and Host protocol.
