# MyAgents-dsh 0.1.21

- Use the dedicated DeepSeek Search API for official DeepSeek canonical search, preventing a lookup from failing because an auxiliary model turn exhausts its server-tool search budget.
- Keep Host-backed and standalone search requests consistent, with structured sources, model-facing summaries, domain restrictions and the existing credential, proxy and cancellation owners.
- Preserve other Provider search protocols and native model-visible tool definitions. Dedicated search no longer reports auxiliary model token usage.

The protocol remains 6.2.0 and the upstream DeepSeek Harness version remains 0.2.1-rc.2. This release does not change Session persistence or the pinned upstream patch set.

Each macOS arm64, macOS Intel x64, Windows x64 and Linux x64 archive is built and validated by the native Release workflow. Exact upstream and patched-artifact provenance is appended by the publisher.
