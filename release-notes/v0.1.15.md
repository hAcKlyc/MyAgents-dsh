# MyAgents-dsh 0.1.15

- Scope declarative component identity by kind and ID, so a command, Skill or MCP server can share a name without rejecting the extension snapshot. Skill references resolve only against Skills.
- Register commands without a description, or with a whitespace-only description, using their name as the description. Keep catalog and execution aliases consistent.
- Report safe MCP failure stages and reasons without exposing server messages, credentials or tool content. Failed MCP components remain isolated; intentional cancellation does not produce failure diagnostics.

The upstream engine remains DSH 0.2.0-rc.2. The Runtime targets macOS arm64, macOS Intel x64, Windows x64 and Linux x64. Each Release archive is built and validated on its native runner; the publication workflow appends exact upstream and patched-artifact provenance.
